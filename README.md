# cv2 inputs to unicode

Real-time **ASCII-art** converter using **OpenCV** and **numpy** — turns webcam, video, or image input into colourful ASCII in the terminal.

## Features

- Colour support via [rich](https://github.com/Textualize/rich)
- Webcam, video-file, or image input
- Real-time conversion

> A fast terminal (e.g. Alacritty) is recommended for the best experience.

## Dependencies

- `numpy`
- `opencv-python`
- `rich`

## Getting started

```sh
pip install numpy opencv-python rich
python src/main.py
```

`src/test.jpg` is included for quick testing.
